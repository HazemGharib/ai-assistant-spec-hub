# Data Model: Platform Foundation & Repository Contracts

**Feature**: `001-platform-foundation`  
**Date**: 2026-09-20

Phase 1 is primarily structural. Entities below model platform metadata and boundary payloads—not a persistent product database.

---

## Entity: Repository

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | string | Canonical: `ai-assistant-ui` \| `ai-assistant-backend` \| `ai-assistant-rag` \| `ai-assistant-mcp` \| `ai-assistant-contracts` \| `ai-assistant-spec-hub` |
| kind | enum | `runtime` \| `contracts` \| `governance` |
| ownershipSummary | string | Required in README |
| inScope | string[] | Documented responsibilities |
| outOfScope | string[] | Explicit non-responsibilities |
| inboundContracts | ContractRef[] | Contracts this repo implements as provider |
| outboundContracts | ContractRef[] | Contracts this repo consumes |
| defaultPort | number \| null | Runtime only; null for contracts/governance |

**Relationships**: Runtime repos *consume* Contracts Package; providers *implement* Communication Boundaries.

---

## Entity: Contract

| Field | Type | Rules |
| ------- | ------ | -------- |
| id | string | Stable id: `ui-backend-chat`, `backend-rag-retrieve`, `backend-mcp-capabilities` |
| boundary | enum | `UI→backend` \| `backend→RAG` \| `backend→MCP` |
| major.minor.patch | semver | Lives on `@ai-assistant/contracts` package version (shared package version for Phase 1) |
| providerRepo | string | Canonical repo name |
| consumerRepos | string[] | Canonical repo names |
| errorModel | object | Required codes: `VALIDATION_ERROR`, `UPSTREAM_UNAVAILABLE`, `INTERNAL_ERROR` |

**Validation**: Boundary contracts MUST live only in `ai-assistant-contracts`. Private types MUST NOT be registered as Contracts.

---

## Entity: Contracts Package

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | string | `@ai-assistant/contracts` |
| version | semver | MAJOR bump on breaking schema/behavior of any boundary |
| exports | module paths | `chat`, `retrieve`, `mcp` (+ root barrel) |

**Relationships**: Produced by `ai-assistant-contracts`; depended on by all runtime repos.

---

## Entity: Environment Profile

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | enum | `isolated` \| `integrated` |
| variables | EnvVar[] | Each has key, purpose, requiredInProfile, example |

### Canonical EnvVar keys (Phase 1)

| Key | Used by | Isolated | Integrated |
| ----- | --------- | ---------- | ------------ |
| `PORT` | backend, rag, mcp | optional (defaults) | optional |
| `VITE_BACKEND_BASE_URL` | ui | unset → local stub adapter | required (e.g. `http://127.0.0.1:3001`) |
| `RAG_BASE_URL` | backend | unset → in-process fake | required (`http://127.0.0.1:3002`) |
| `MCP_SERVER_URL` | backend | unset → in-process fake | required when HTTP transport |
| `CONTRACTS_PACKAGE_VERSION` | optional audit scripts | optional | optional |

No auth secrets required for inter-service trust in Phase 1.

## Entity: ChatTurn (UI ↔ backend payload)

| Field | Type | Rules |
| ------- | ------ | -------- |
| conversationId | string (uuid) | Generated by UI or backend; echoed |
| messageId | string (uuid) | Per user message |
| role | enum | `user` \| `assistant` \| `system` |
| content | string | Non-empty for user messages |
| createdAt | string (ISO-8601) | Required |

### ChatResponse

| Field | Type | Rules |
| ------- | ------ | -------- |
| conversationId | string | Matches request |
| message | ChatTurn | `role=assistant` |
| citations | Citation[] | Optional; empty OK in Phase 1 stubs |
| toolInvocations | ToolInvocationSummary[] | Optional; present when MCP used |
| diagnostics | object | Optional: which boundaries were hit (`rag`, `mcp`) for smoke verification |

| source | string | Required |
| score | number | 0–1 stub OK |
| title | string \| null | Optional |

### RetrieveResult

| Field | Type | Rules |
| ------- | ------ | -------- |

## Entity: McpToolDescriptor / ToolCall (backend ↔ MCP)

### McpToolDescriptor

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | string | e.g. `smoke_ping` |
| description | string | Required |
| inputSchema | JSON Schema / Zod | Required |

### ToolCallRequest

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | string | Must be registered |
| arguments | object | Validated against schema |

### ToolCallResult

| Field | Type | Rules |
| ------- | ------ | -------- |
| name | string | Echo |
| ok | boolean | Required |
| content | string \| object | Required on success |
| error | { code, message } \| null | Required on failure |

---

## Entity: SmokePathResult (verification record)

| Field | Type | Rules |
| ------- | ------ | -------- |
| startedAt / finishedAt | ISO-8601 | Required |
| hitRag | boolean | Must be true for Phase 1 pass |
| hitMcp | boolean | Must be true for Phase 1 pass |
| contractPackageVersion | string | Must match installed package |
| errors | string[] | Empty on success |

**State transitions**: `not_started` → `running` → `passed` \| `failed`. Failure of integrated smoke while isolated tests pass ⇒ Phase 1 incomplete.

---

## Lifecycle notes

- **Contracts package**: `0.1.0` initial → bump per `contracts/versioning.md`
- **Repositories**: created once; ownership docs updated when boundaries change
- **No durable DB** in Phase 1; all stub state may be in-memory
